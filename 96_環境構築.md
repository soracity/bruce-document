# Angular + Capacitor + SQLite 導入手順

## 1. Capacitor導入

```bash
npm install @capacitor/core
npm install @capacitor/cli --save-dev
```

---

## 2. Capacitor初期化

```bash
npx cap init
```

入力例：

```text
App name: Tennis Stats
App ID: com.example.tennis
```

---

## 3. Android/iOSプラットフォーム追加

### Android

```bash
npm install @capacitor/android

npm run build

「capacitor.config.ts」を編集
================================
import type { CapacitorConfig } from '@capacitor/cli';

const config: CapacitorConfig = {
  appId: 'io.github.soracity.bruce',
  appName: 'Bruce',
  webDir: 'dist/feature-20251212/browser' // ここのパスをチェック
};
  
export default config;
================================


npx cap add android
```

### iOS（Macのみ）

```bash
npm install @capacitor/ios
npx cap add ios
```

```bash
npm install @capacitor-community/sqlite
npm install jeep-sqlite
npm install sql.js
```

## 5. Angular build

```bash
npm run build
```

## 6. Capacitor同期

```bash
npx cap sync
```

# SQLite Service 作成例

```ts
import { Injectable } from '@angular/core';
import {
  CapacitorSQLite,
  SQLiteConnection,
  SQLiteDBConnection,
} from '@capacitor-community/sqlite';

@Injectable({
  providedIn: 'root',
})
export class SqliteService {

  private sqlite = new SQLiteConnection(CapacitorSQLite);
  private db!: SQLiteDBConnection;

  async initialize(): Promise<void> {

    this.db = await this.sqlite.createConnection(
      'tennis-db',
      false,
      'no-encryption',
      1,
      false
    );

    await this.db.open();

    await this.db.execute(`
      CREATE TABLE IF NOT EXISTS score_outcome (
        point_id TEXT PRIMARY KEY,
        match_id TEXT,
        json TEXT
      );
    `);
  }
}
```

## 4. 設定・検証の補足

| 対象 | 設定・検証内容 | 注意 |
| --- | --- | --- |
| `angular.json` | `"styles": ["node_modules/catw/styles/catw.css", "src/styles.scss"]`（対象アプリのbuild設定内） | CSSの重複読み込みを避ける。Angular生成時のstyles配列を置き換える場合も他の設定は維持 |
| `capacitor.config.ts` | `appId: 'io.github.soracity.bruce'`、`appName: 'Bruce'`、`webDir: 'dist/bruce/browser'` | 新規Angularの実際の出力フォルダを確認して設定。旧Bruceの `dist/feature-20251212/browser` は使わない |
| `src/main.ts` | Webのとき `jeep-sqlite` 読込後にAngular起動。既存BruceのWeb初期化実装を参照 | Webアセットのパス／読込完了待ちを確認 |
| DB接続管理 | iOS・AndroidとWebで同じSQLite APIを使用。Webでは `initWebStore()` と永続保存を実装 | IndexedDBへ保存されてもDexieは不要 |
| catw連携 | catwの公開APIのみインポート。i18nはcatwの `I18nTextPort` とBruce側サービスを接続 | 旧Bruceの共通実装をコピーしない |
| `catw.css` | catwビルド時に自動生成。新規Bruceは生成済みCSSを読み込む | Bruce固有画面のCSSは別途SCSSで記述。catwのCSSはBruceの全クラスを自動生成するものではない |
| 確認順序 | `npm run build` → `npm start` → ブラウザでDB検証 → `npx cap sync` → 端末検証 | 実機で成功したと確認できるまでは完了扱いしない |
| ローカルcatw更新 | catwを修正したら `npm run build` → `npm pack ./dist/catw --pack-destination .` → 新規Bruce側で再インストール | ローカルのtgzは自動リンクではない。再パック・再導入が必要 |
| セキュリティ | `npm audit` で脆弱性を確認 | 互換性を壊しうる `npm audit fix --force` は無断で行わない |

# Angular + Capacitor + SQLite 導入手順

## 1. Capacitor導入

```bash
npm install @capacitor/core
npm install @capacitor/cli --save-dev
```

---

## 2. Capacitor初期化

```bash
npx cap init
```

入力例：

```text
App name: Tennis Stats
App ID: com.example.tennis
```

---

## 3. Android/iOSプラットフォーム追加

### Android

```bash
npm install @capacitor/android

npm run build

「capacitor.config.ts」を編集
================================
import type { CapacitorConfig } from '@capacitor/cli';

const config: CapacitorConfig = {
  appId: 'io.github.soracity.bruce',
  appName: 'Bruce',
  webDir: 'dist/feature-20251212/browser' // ここのパスをチェック
};
  
export default config;
================================


npx cap add android
```

### iOS（Macのみ）

```bash
npm install @capacitor/ios
npx cap add ios
```

```bash
npm install @capacitor-community/sqlite
npm install jeep-sqlite
npm install sql.js
```

## 5. Angular build

```bash
npm run build
```

## 6. Capacitor同期

```bash
npx cap sync
```

# SQLite Service 作成例

```ts
import { Injectable } from '@angular/core';
import {
  CapacitorSQLite,
  SQLiteConnection,
  SQLiteDBConnection,
} from '@capacitor-community/sqlite';

@Injectable({
  providedIn: 'root',
})
export class SqliteService {

  private sqlite = new SQLiteConnection(CapacitorSQLite);
  private db!: SQLiteDBConnection;

  async initialize(): Promise<void> {

    this.db = await this.sqlite.createConnection(
      'tennis-db',
      false,
      'no-encryption',
      1,
      false
    );

    await this.db.open();

    await this.db.execute(`
      CREATE TABLE IF NOT EXISTS score_outcome (
        point_id TEXT PRIMARY KEY,
        match_id TEXT,
        json TEXT
      );
    `);
  }
}
```

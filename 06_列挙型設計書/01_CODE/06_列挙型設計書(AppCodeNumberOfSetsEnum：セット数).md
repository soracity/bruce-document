## 列挙型設計書

#### 列挙型名称
- 論理名：セット数
- 物理名：AppCodeNumberOfSetsEnum
- ファイル名：app-code-number-of-sets.enum.ts

#### 列挙種別
- [x] 一般列挙型
- [ ] ラベル列挙型
- [ ] メッセージ列挙型

| 列挙種別 | 意味 |
|---|---|
| 一般列挙型 | 列挙名、値で構成される列挙型 |
| ラベル列挙型 | ラベルの列挙型 |
| メッセージ列挙型 | メッセージの列挙型 |

#### 列挙型パッケージ
app\brf9000\brf9011-enum\code

#### 列挙型定義
| No | 列挙名 | 値 | 型 | 説明 |
| --- | :--- | :--- | :--- | :--- |
| 00 |SET1|1|文字列| SET1 |
| 01 |SET3|3|文字列| SET3 |
| 02 |SET5|5|文字列| SET5 |
| 03 |SET_NON|0|文字列| セットなし |

  - 値説明
  - lbl.<"comn" | 機能ID>.<label key>
  - msg.<"comn" | 機能ID>.<label key>

#### 留意事項
- 型
  - 文字列：string
  - 数値：number
- 列挙型定義テーブルの型はすべて同じ必要があります

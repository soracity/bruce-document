## 列挙型設計書

#### 列挙型名称
- 論理名：マーキー移動方式
- 物理名：AppCodeMarqueeModeEnum
- ファイル名：app-code-marquee-mode.enum.ts

#### 列挙種別
- [ ] 一般列挙型
- [x] コード列挙型
- [ ] ラベル列挙型
- [ ] メッセージ列挙型

| 列挙種別 | 意味 |
|---|---|
| 一般列挙型 | 列挙名、値で構成される列挙型 |
| コード列挙型 | コード値の列挙型 |
| ラベル列挙型 | ラベルの列挙型 |
| メッセージ列挙型 | メッセージの列挙型 |

#### 列挙型パッケージ
app\brf9000\brf9011-enum\code

#### 列挙型定義
| No | 列挙名 | 値 | 型 | 説明 |
|---|---|---|---|---|
| 01 | BOUNCE | bounce | 文字列 | 左から右へ流れ、右端で方向を反転して左へ流れ、左端で再び反転する。左右への往復を繰り返す |
| 02 | RESTART | restart | 文字列 | 左から右へ流れ、右端に達したらアニメーションで逆行せず左側の先頭位置へ戻り、再び右へ流れる動作を繰り返す |

  - 値説明
  - lbl.<"comn" | 機能ID>.<label key>
  - msg.<"comn" | 機能ID>.<label key>

#### 留意事項
- 型
  - 文字列：string
  - 数値：number
- 列挙型定義テーブルの型はすべて同じ必要があります
- ACGによるTypeScript列挙型の自動生成用設計書。生成対象Enumクラスの手書き追加は行わない。
- **要求として承認された動作**：マーキー表示中の移動方式は、左右往復と、右端到達後に左端へ戻って右向き移動を繰り返す一方向型の2種類からComponentパラメーターで選択できる。
- **適用条件**：文字列表示方式がMARQUEEの場合だけ本列挙型を参照し、WRAP・ELLIPSIS時はマーキー移動方式を適用しない。
- **設計案で未承認**：物理名・ファイル名・列挙名・値・Component入力パラメーター名・デフォルト方式。
- **実装時の未決事項**：移動速度、端での一時停止、戻り方の視覚効果、文字列が収まる場合のアニメーション有無、動きを減らすOS設定への対応。
- **状態**：設計書作成。ACG生成・共通Component実装・検証は未実施。

#### （５）型
- 文字列：string
- 数値：number
- 日付：string
- 真偽：boolean
- Enum：既存の自動生成Enum型をComponent DTO（UI Form DTO）のFormControl型として指定可能

Enumを指定した場合、ACGはEnumそのものを画面設計書から新規生成しない。既存の自動生成Enumを参照・importしてComponent DTOのFormControl型として使用する。

#### （６）Enum型
`型=Enum`の場合は`Enum型`を必須指定する。

`Enum型`には、既存の列挙型設計書から自動生成されるEnumの物理名を指定する。

例：

- 試合タイプ：`AppCodeMatchTypeEnum`
- 試合設定：`AppCodeMatchSettingEnum`
- セット設定：`AppCodeNumberOfSetsEnum`
- ゲーム確定：`AppCodeGameFinalEnum`
- 状態：`AppCodeMatchStatusEnum`
- タイブレークモード：`AppCodeTieBreakEnum`
- コートサイド：`AppCodeCourtSideEnum`

`型!=Enum`の場合は`Enum型=-`とする。

ACGは`型=Enum`の場合、指定されたEnum型をimportし、FormControlの型として使用する。

Enum型自体の生成責務は列挙型設計書側にあり、画面設計書から同一Enumを重複生成しない。

#### （７）文字種
文字種は文字列型の場合のみ指定する。

- ASCII
- Unicode

文字列以外の型は `-` とする。

#### （８）Validation

##### 文字列

###### Unicode
指定可能なValidationは以下のみとする。

- 必須
- 文字数(最小/最大)

`Unicode`はUnicode専用Validatorを生成する指定ではない。ASCII限定の文字種チェックを行わず、Unicode文字の入力を許可することを表す。

`Unicode`指定時は以下を指定してはならない。

- 形式
- 必須(真偽)
- 数値(最小/最大)
- 正規表現

###### ASCII
指定可能なValidationは以下とする。

- 形式
  - 半角数字
  - 半角英数字
  - 半角英数字記号
  - 正規表現
- 必須
- 文字数(最小/最大)

`ASCII`指定時は以下を指定してはならない。

- 必須(真偽)
- 数値(最小/最大)

`形式=正規表現`を指定する場合のみ、`正規表現`列にパターンを指定する。

##### 真偽
指定可能なValidationは以下のみとする。

- 必須(真偽)

以下を指定してはならない。

- 文字種
- 形式
- 必須
- 文字数(最小/最大)
- 数値(最小/最大)
- 正規表現

##### 数値
指定可能なValidationは以下とする。

- 必須
- 数値(最小/最大)

以下を指定してはならない。

- 文字種
- 形式
- 必須(真偽)
- 文字数(最小/最大)
- 正規表現

##### Enum
指定可能なValidationは以下とする。

- 必須

以下を指定してはならない。

- 文字種
- 形式
- 必須(真偽)
- 文字数(最小/最大)
- 数値(最小/最大)
- 正規表現

Enum値として許可される値の定義は、参照する列挙型設計書および自動生成Enumを正とする。画面設計書側で同じ候補値をValidationとして重複定義しない。

#### （９）Validation指定値
- 必須
  - `〇`：`Validators.required`生成対象
  - `-`：未指定
- 必須(真偽)
  - `〇`：`Validators.requiredTrue`生成対象
  - `-`：未指定
- 文字数(最小/最大)
  - `最小/最大`で指定する。
  - 最小のみ未指定の場合は `-/最大` とする。
  - 最大のみ未指定の場合は `最小/-` とする。
  - 両方未指定の場合は `-` とする。
- 数値(最小/最大)
  - `最小/最大`で指定する。
  - 最小のみ未指定の場合は `-/最大` とする。
  - 最大のみ未指定の場合は `最小/-` とする。
  - 両方未指定の場合は `-` とする。

#### （１０）ACG Validation仕様チェック
ACGはDTO生成前に、型・Enum型・文字種・Validation指定の組み合わせを検証する。

本設計書のValidationルールに反する指定が存在する場合、ACGは値を補正・無視して生成を継続してはならない。Exceptionを発生させ、コード生成を停止する。

例：

- `型=文字列`、`文字種=Unicode`、`形式=半角数字` → Exception
- `型=文字列`、`文字種=ASCII`、`数値(最小/最大)=0/100` → Exception
- `型=真偽`、`必須=〇` → Exception
- `型=数値`、`文字数(最小/最大)=1/3` → Exception
- `形式=正規表現`で`正規表現`列が未指定 → Exception
- `形式!=正規表現`で`正規表現`列が指定されている → Exception
- `型=Enum`で`Enum型`が未指定 → Exception
- `型!=Enum`で`Enum型`が指定されている → Exception
- `型=Enum`で文字種・形式・必須(真偽)・文字数・数値範囲・正規表現のいずれかが指定されている → Exception

Exceptionメッセージには、少なくとも以下を含める。

- 物理名
- 型
- Enum型
- 文字種
- 不正な指定項目
- 不正理由

例：

```text
画面設計書のDTO項目定義が不正です。
物理名: playerName
型: 文字列
Enum型: -
文字種: Unicode
不正項目: 形式=半角英数字
理由: Unicode指定時は形式チェックを指定できません。
```

ACGは不正な設計書を推測して補正しない。Fail Fastで生成を停止する。

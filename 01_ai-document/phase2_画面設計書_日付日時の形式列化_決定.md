# Phase2 画面設計書 日付・日時の形式列化 決定

> 状態：設計承認済み  
> 承認日：2026-10-16

## 決定内容

画面設計書の `型` 列では、TypeScript上の型を表す。

現在、`日付` および `日時` はTypeScript上ではいずれも `string` として扱っており、`文字列` と型として区別する意味がない。

そのため、画面設計書では `日付`・`日時` を `型` 列ではなく `形式` 列で表現する。

概念は以下とする。

```text
文字列
  ├─ 形式なし
  ├─ 日付
  └─ 日時
```

例：

```text
日付項目
型   = 文字列
形式 = 日付

日時項目
型   = 文字列
形式 = 日時
```

生成されるTypeScript型はいずれも `string` とする。

```ts
FormControl<string>
```

## 意図

`型` はTypeScript上の型責務、`形式` は値の表現・入力形式の責務として分離する。

これにより、画面設計書で `文字列`・`日付`・`日時` を別型として扱う曖昧さをなくす。

## 未決事項

以下は別途設計する。

- `形式=日付` の具体的な入力・Validation仕様
- `形式=日時` の具体的な入力・Validation仕様
- `文字種` 列との組み合わせルール
- 共通 `TypeScriptTypeEnum` に存在する `DATE` / `DATE_TIME` を他設計書も含めてどう扱うか

本決定は、まず画面設計書において `日付`・`日時` を `型` ではなく `形式` として扱うことを対象とする。

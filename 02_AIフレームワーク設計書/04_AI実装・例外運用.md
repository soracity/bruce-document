# AI実装・例外運用設計（暫定・全件監査前）

根拠：[2.8](../01_ai-document/phase2_08_AI実装制約.md)、[2.1](../01_ai-document/phase2_01_責務境界.md)。

| ID | 現行承認事項 |
|---|---|
| BRUCE-AI-001 | AIは既存LayoutManager・共通Component・承認済みACG生成規則を使用し、独自CSSやComponentで設計思想を迂回しない。 |
| BRUCE-AI-002 | ACG生成物を直接修正しない。生成元定義と生成処理を修正して再生成する。 |
| BRUCE-AI-003 | 通常の承認済み仕様範囲での実装に個別承認は不要。設計逸脱が必要なときは停止し、原因・影響・既存案に沿う代替策を検討する。 |
| BRUCE-AI-004 | 承認済み方式で進められないときは理由・影響・代替案を示し、ユーザーの明示承認後に変更する。 |
| BRUCE-AI-005 | 中断時はAI自身の未完了変更を正常化または安全に戻し、原則として変更前と同等のビルド可能状態を確保する。他者の変更を勝手に戻さない。 |
| BRUCE-AI-006 | GitHubに承認原案・参照・進捗・変更ファイル・エラー・試行結果・ビルド復旧状態・次回手順・禁止代替案を記録。再開時は記録を最初に確認。 |
| BRUCE-AI-007 | 復旧やビルド確認が不能なら正常停止を装わず、残存リスクと再開手順を報告する。 |

# 01 アーキテクチャ・責務境界（作成途中）

> 状態：**部分抽出・未監査**。この文書はPhase 5実装の最終正本として未承認。議事録の全件照合前に完了扱いしない。

## 現行の責務分担

| 仕様ID | 対象 | 確認された設計規則 | 根拠 |
|---|---|---|---|
| BRUCE-ARC-001 | 画面Component | 表示、操作受付、画面状態、Application呼出しを担当。DB直接アクセス・Domain判断・共通部品内部デザインは担当しない | [Phase 2.1](../01_ai-document/phase2_01_責務境界.md) 2.1.1 |
| BRUCE-ARC-002 | LayoutManager | 外側の配置・幅比率・横並び・折り返し・間隔を担当。入力値・業務判断・Application呼出しを持たない | 同上 |
| BRUCE-ARC-003 | 共通Component | 自身の内部表示、操作、FormControl連携、汎用イベント通知を担当。画面固有処理やDBアクセスを持たない | 同上 |
| BRUCE-ARC-004 | Application | ユースケースの調整とDomain・Infrastructure呼出し順序を担当。UI描画やCSSを持たない | 同上 |
| BRUCE-ARC-005 | Domain | 業務ルール、状態遷移、業務整合性を担当。Angular・SQLite・RESTに依存しない | 同上 |
| BRUCE-ARC-006 | Infrastructure | DB・REST・端末機能等の技術的処理を担当。業務ルール・画面表示判断を持たない | 同上 |
| BRUCE-ARC-007 | DTO/FormGroup | 画面入力値・入力状態・画面入力Validation状態を保持し、DB処理・業務ルール・画面遷移を持たない | 同上 |
| BRUCE-ARC-008 | 画面CSS | 画面独自のflex/grid/widthや共通Component内部への任意CSS注入で配置を迂回しない。画面はLayoutManagerと共通Componentを組み合わせる | 同上 2.1.1・2.1.2 |

|---|---|---|---|
| BRUCE-SPACE-001 | LayoutItem | 同一行の兄弟Component間の横gapを管理 | [Phase 2.3](../01_ai-document/phase2_03_余白の責務.md) 2.3.1 |
| BRUCE-SPACE-002 | ItemStackLayout | 行と行の縦gapを管理 | 同上 |
| BRUCE-SPACE-003 | 共通Component | 自身の内部padding/gapを管理 | 同上 |
| BRUCE-SPACE-004 | 画面外周 | 上位Containerがpaddingを管理する。新規ScreenLayoutの採用や数値（例16px）は未承認 | 同上 2.3.2、2026-10-19承認 |
| BRUCE-SPACE-005 | margin禁止 | 画面側から共通Componentにmr-*/mt-*等を与えて兄弟間隔・行間を調整しない | 同上 2.3.1 |
| BRUCE-SPACE-006 | gap追加API | gapSize等の新規Input/Enumは現段階では追加しない。必要性が具体化したときに再検討 | 同上 2.3.3 |

## ComponentBaseの現行承認構造

| 仕様ID | 設計規則 | 根拠 |
|---|---|---|
| BRUCE-BASE-001 | 共通スタイルInputをComponentBaseに一元定義し、子Componentで再定義しない | [Phase 3.3](../01_ai-document/phase3_03_ComponentBase.md) 2026-10-20追加承認 |
| BRUCE-BASE-002 | FormControlComponentBase<T>はComponentBaseを継承し、FormControlと変更検知を担当。FormControl不要のComponentはComponentBaseを直接継承 | 同上、2026-10-20正式承認 |
| BRUCE-BASE-003 | Component固有の既定値は基底クラスのprotected既定値取得メソッドをoverride。画面からの明示指定を最優先 | 同上、2026-10-20追加承認 |
| BRUCE-BASE-004 | ComponentBaseに任意FormControlを統合する旧単一基底案は撤回済みであり、現行実装指示に使用しない | 同上、2026-10-20正式承認 |

| BRUCE-SWIPE-004 | Table横スクロールとのジェスチャー競合はPhase 7で実機検証する（検証済みとはしない） | 同上 |

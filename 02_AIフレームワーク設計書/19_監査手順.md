## 原典→設計の意味照合

17の各単位を原文で読み、複数の規則を含む文・表行・コードは原子仕様へ分割する。各原子仕様には原典位置、当時の承認状態、後日の変更根拠、現行有効性、種別、16の規則ID、実装仕様節、09の実装対象、14のテストを対応させる。

種別は仕様/理由/禁止/例外/コード例/調査結果/未決/運用履歴。承認語が含まれるだけで現行承認と分類しない。旧提案を後日承認と比較し、置換した根拠は18へ記録する。同一文でも日付/文脈が異なるため無条件に重複削除しない。候補なし/不明/本文不足を残したままA合格にしない。

## 設計→原典の逆照合

本文の全公開Input/型/既定値/処理分岐/禁止/例外を取り出し、16と原典の位置へ戻す。原典から直接導かれない新しい振る舞いは未承認へ分離する。承認仕様を実現する内部Helper/Observer/診断番号等の実装詳細は、上位の根拠と不変条件を示す。

規則IDが存在するだけでは合格にしない。設計が原典より許可を広げたり狭めたりしていないか、入力値・イベント・DOM・CSS・エラーが一致するかを確認する。

## 設計単独の実装監査

実装対象ごとに、ソース/議事録を見ない実装者が以下を決められるか検査する。

| 検査対象 | 合格条件 |
|---|---|
| 構造 | ファイル/種類/責務/依存方向/DIスコープが決まる |
| データ | 全プロパティ/型/可視性/既定値/初期化/所有者が決まる |
| API | 全メソッド/引数/戻り値/副作用/通知順が決まる |
| 処理 | 全正常/境界/異常/非同期/再入/破棄の分岐が決まる |
| 表示 | HTML/投影/実体DOM/ARIAとCSS値/適用先/優先順位が決まる |
| 移行 | 旧API呼出しを特定し互換性と置換順が決まる |
| テスト | 入力/操作/期待値が具体的で、未決期待値がない |

未決事項は18へ具体案/影響/推奨を記載する。実装者に議事録を読ませて仕様を選ばせる状態はB不合格。実装済みコードの貼付けだけで承認仕様を満たす設計にしたとも扱わない。

## 文書・計算の検査

Markdownのローカルリンク先、fenceの閉鎖、規則/実装/テストIDの重複と参照、旧16件不変、既存コード固定SHAを検査する。gap控除/再配分/行分割/十進合計/日付UTC往復の代表例を純粋計算で確認する。ブラウザーで未測定の描画・Pointer・ARIAを計算だけで成功にしない。

機械検査の成功は文書構造の検査であり、意味照合や実装試験ではない。アプリのAngular/Java/CI/実機実行は14章のケースとして別証跡を取る。

## 判定と保存

A合格 AND B合格だけを完成とする。保存は単一コミットの作業ブランチで行い、更新前のheadを照合して他者更新を上書きしない。保存後にGitHubのrefとツリー内容を読み直す。main反映前に作業状態/残件/検査結果の記載を更新する。

## 今回実行した構造検査の再現コード

リポジトリrootで次のPythonを実行する。旧16件不変、ローカルリンク、fence、WBS件数/状態を検査する。原典の意味照合合格を検査するコードではない。

```python
from pathlib import Path
import re,json,subprocess,collections
repo=Path.cwd();root=repo/'02_AIフレームワーク設計書'
missing=[];fences=[]
for p in sorted(root.glob('*.md')):
 inside=False;fence=None
 for n,line in enumerate(p.read_text().splitlines(),1):
  if re.match(r'^\s*```',line): inside=not inside;continue
  if inside:continue
  for m in re.finditer(r'(?<!\\)\[[^\]]+\]\(([^\s)]+)(?:\s+"[^"]*")?\)',line):
   target=m[1]
   if re.match(r'^(?:https?:|mailto:|#)',target):continue
   target=target.split('#')[0]
   if not (p.parent/target).exists():missing.append((p.name,n,target))
 if inside:fences.append(p.name)
# 原典旧16件不変はHEAD baselineと実体を比較する。
old=[]
for p in sorted((repo/'01_ai-document/議事録バックアップ').glob('*.md')):
 b=subprocess.check_output(['git','show','bde56a6eba071b7b80cd6ec66d173e4cfb59736d:'+str(p.relative_to(repo))],cwd=repo)
 old.append(b==p.read_bytes())
s=(repo/'01_ai-document/AIフレームワーク_進捗管理表.md').read_text();rows=[]
for line in s.splitlines():
 a=[x.strip().replace('**','') for x in line.split('|')]
 if len(a)>=11 and re.fullmatch(r'\d+\.\d+\.\d+',a[3]):rows.append(a)
counts=collections.Counter(a[5] for a in rows)
r={'documents':len(list(root.glob('*.md'))),'missingLocalLinks':missing,'unclosedFences':fences,'oldMinutesUnchanged':all(old),'oldCount':len(old),'wbsRows':len(rows),'wbsStates':dict(counts)}
print(json.dumps(r,ensure_ascii=False,indent=2))
assert not missing and not fences and all(old)
assert len(old)==16 and len(rows)==79
assert counts=={'完了':49,'進行中':1,'未着手':29}
```

# 通常UIの内部実装契約

公開Input・Output・protected既定値の正本は02/13章。本章はそれを実現する内部型・状態・関数・テンプレート接続の正本。旧27章の重複案は採用しない。P-01/P-03は工程②成果と一緒に承認を受ける設計案であり、既存承認を取得した表示にはしない。

## UIIMPL-01 スタイルの有効化と適用

ComponentBaseは02章の全Inputを一度だけ宣言する。assertInputs():voidはundefined以外のboolean/数値/Enum実体を許容表で検査し、不正ならBRUCE_STYLE_VALUE。nullも不正。computedの最初に検査し、false/0を有効値とする。

protected shouldApply(group:'border'|'rounded'|'shadow'|'padding'):booleanを追加する（内部API）。raw Inputが一つでも指定済み、またはその群の既定値メソッドがComponentBase.prototypeの同じメソッドと関数同一でなければtrue。例えばpadding=0、getDefaultPadding overrideはいずれも有効。戻り値の等価比較ではoverrideの意図を失うため判定しない。基底以外の任意オブジェクトへprototype操作を公開しない。

| 群 | 明示Input／overrideとして調べるメソッド | 出力 |
|---|---|---|
| border | border,borderWidth / getDefaultBorder,getDefaultBorderWidth | getBorderClass(effectiveBorder,effectiveBorderWidth) |
| rounded | rounded,roundedSize / getDefaultRounded,getDefaultRoundedSize | getRoundedClass。FAB円形の例外は下記 |
| shadow | shadow,shadowSize / getDefaultShadow,getDefaultShadowSize | getShadowClass |
| padding | padding / getDefaultPadding | getPaddingClass |

styleClasses:Signal<string>は有効な群の固定変換結果と色クラスだけを空白結合。visibleはhostのbruce-hiddenへ別適用。backgroundForStyle()/textForStyle():AppUiColorEnum|undefinedは通常effective値、Cellは03章の色解決。Buttonの背景未指定時だけbackgroundForStyleはundefinedとし、意味色を内部variantClassへ渡す。variantClassはPRIMARY→btn-primary、SECONDARY→btn-secondary、ACCENT→btn-accent、NEUTRAL→btn-neutral、INFO/SUCCESS/WARNING/ERROR→同名btn-*の固定Map。BASE_100/200/300は固定bruce-btn-base-100/200/300で--btn-colorを対応する--color-base-*へ設定。undefinedはbtn-secondary。明示背景だけ通常bg-*限定CSSで塗る。btn-outlineの未指定背景は変更しない。

FABはgetDefaultBackgroundColor=PRIMARY、getDefaultShadow=true、getDefaultShadowSize=lg。静的shadow-lgを削除し、shadow群からshadow-lg/sm/md/noneのうち1種類だけを出す。btn-circleは維持し、rounded/roundedSize明示またはそのメソッドのoverrideがない限り丸めクラスを出さない。明示rounded=falseは半径0。Alertの未指定色は既存level/variant表示。Table/Recordは各自の色を塗らずCellへ渡す。

## UIIMPL-02 FormControl通知・再接続

FormControlComponentBase<T>のprivate状態はcurrentControl?:FormControl<T>、controlSubscription?:Subscription、destroyed=false。protected onControlBound(previous,current):void、onControlValue(value:T):void、onControlStatus(status:FormControlStatus):voidの既定本体は空。必須部品のrequireControlは未指定をBRUCE_CONTROL_REQUIREDとする。

control Inputだけを読むeffectからuntracked(()=>bindControl(next))を呼ぶ。同一参照ならreturn。旧購読解除→currentControlをnextへ更新→nextのvalueChanges/statusChangesを個別購読→onControlBound(previous,next)→markForCheck。value通知はonControlValue→markForCheck、status通知はonControlStatus→markForCheck。Dateのown validatorの取付け/解除はonControlBoundが担当する。01章の外部ロードはemitEvent:true、画面の自動保存抑止は01章のapplyingResultで行う。silent patchを検出するpollingや追加の画面Inputを作らない。

destroyはdestroyed=true→購読解除→参照破棄。派生クラスは自分の資源を解除後super.ngOnDestroy。controlの値を複製せず、基底からOutputをemitしない。後続microtaskはdestroyedを確認する。

## UIIMPL-03 テンプレートの全依存と翻訳

全部品はstandalone:true、changeDetection:OnPush、host display:block/min-width:0（FAB配置例外は13章）、host class.bruce-hidden=!effectiveVisible()。02章のstyleClassesは内部の適用要素だけへ付ける。Button/FABはnative button、Textbox/Dateはinput、RadioはRADIO時input/BUTTON時label、ToggleはSLIDE時input/BUTTON時label、Groupはfieldset、Alertはrole=alert、Labelはviewport。hostと内部へ同じpaddingを二重適用しない。

| Component | readonly参照／imports | テンプレートから呼ぶ追加メンバー |
|---|---|---|
| Textbox | ReactiveFormsModule,Brf9018I18nLabelPipe | requireControl。label/placeholder/keyは13章 |
| Date | Brf9018I18nLabelPipe | nativeInput:viewChild.required<ElementRef<HTMLInputElement>>、displayValue:signal('')、onInput/onBlur |
| Radio | ReactiveFormsModule、InputType=AppComponentInputTypeRadioEnum | optionLabel(i,option):string、onChange():void、destroyed=false |
| Toggle | InputType=AppComponentInputTypeToggleEnum | resolvedLabel:computed<string>、isChecked/isDisabled、onChange/onBlur |
| Button | 共通Angular Signal/ViewChild API | resolvedText:computed<string>、variantClass:computed<string>、viewport/track:required viewChild、onClick |
| Label | 同上 | resolvedText、viewport/track、controller?:TextOverflowController |
| Alert | Brf9018I18nMessagePipe、enumButtonMsg=AppComponentInputTypeAlertButtonMsgTypeEnum | levelClass/backgroundVariantClass/buttonVariantClass/icon/resolvedMessage:各computedまたは純関数 |

label解決はBra9010Service（src/app/brf9000/brf9010-i18n/application/service/bra9010.service.ts）のgetLabel/getMessageを使用する。固定ソース86583cbaでBrf9018I18nLabelPipeが同じサービスを呼ぶことを確認した。存在しないBrf9018I18nServiceや言語変更Observableを仮定しない。

内部I18nTextPort={label(key:K):string,message(key:AppI18nMessageKeyEnumIf):string,watch(listener:()=>void):()=>void}をbrf9018-pipe/i18n-text.port.tsへ置く。Angular injection contextでBra9010ServiceとInjectorを取得。label/messageはサービスへそのまま委譲、未解決は既存の空文字を維持。watchはeffect内でservice.getCurrentLanguage()を読み、untracked(listener)を呼ぶ。返却はEffectRef.destroy。getCurrentLanguageは現在のSignalを読むため、言語変更がこのeffectと解決computedへ伝播する。Label/Button等のresolvedText/resolvedLabelはキーInputとport.labelを読むcomputed、effectでその結果をcontroller.update/計測invalidateへ渡す。サービスのキャッシュloadはinitialize/changeLanguageのawait完了後のlanguage更新を契機にする。同一言語のラベル再読込みを明示利用する場合の内部拡張はBra9010Serviceのprivate revision=signal(0)、loadLabels成功でrevision.update(n=>n+1)、getLabel/getMessageでrevision()を読む形とし、既存公開APIを増やさない。通信失敗時はrevision/言語を進めない。

## UIIMPL-04 Dateの状態とnative編集バッファ

親controlはNullable<string>、typeは既存Date Enum。private draftError:signal<DateFailure|null>、attachedControl?:FormControl、original?:{utc:string,input:string}、selfWrite=false、destroyed=false。inputValidator:ValidatorFnはインスタンスごと1関数で、draftErrorなら{dateInput:failure}、なければnull。addValidators/removeValidatorsはこの関数だけを対象にし、他のValidatorをclearしない。

native inputに#nativeInput、[type]=type().value、step=any、[disabled]=requireControl().disabled、(input)/(blur)を付ける。**[value]と[formControl]を付けない。** onInputはnative validityを読んでdisplayValueへ記録するがDOM valueへ書かない。badInput=trueならincomplete、typeMismatch/range/step異常またはcodec失敗なら該当エラーをdraftErrorへ設定し、親値は保持、dirty→updateValueAndValidity({emitEvent:false})→markForCheck。badInput=falseかつraw=''は有効未入力として''を親へsetValue。成功はdraftError解除→selfWrite=true→setValue(value,{emitEvent:true})→dirty→finally selfWrite=false。自分のvalue通知は表示へ再書込みしない。blurはtouchedのみ。

外部value通知はdraftError/old originalを破棄しcodec.toInput。成功ならnativeInput.nativeElement.value=textを一度書きdisplayValue=text、DATE_TIMEならoriginalを保存。不正な保存値は親値を消さずinvalidStoredValue、表示''。null/''は未入力でDate自身はrequiredエラーにしない。status通知はdisabled更新のみ。bind時は前の関数を除去し旧controlをsilent再検証→新controlへ追加→現在値を同期→再検証。viewChild未生成ならafterNextRenderまで最新値を1件保留。type変更effectはoriginal/draftを破棄し現在の親値を新typeで検査。DATEとDATE_TIMEの意味を自動変換しない。

### codecの完全型

```ts
type DateReason='incomplete'|'invalidDate'|'invalidUtc'|'invalidLocalValue'|'nonexistentLocalTime'|'outOfRange'|'invalidStoredValue';
type DateFailure={reason:DateReason;raw:string};
type Result<T>={ok:true;value:T}|{ok:false;error:DateFailure};
type DateParts={year:number;month:number;day:number};
type LocalParts=DateParts&{hour:number;minute:number;second:number;millisecond:number};
// parseDate(raw:string):Result<DateParts>
// parseLocal(raw:string):Result<LocalParts>
// toInput(value:Nullable<string>,type:AppComponentInputTypeDateEnum):Result<{text:string;original?:{utc:string;input:string}}>
// fromInput(raw:string,type:AppComponentInputTypeDateEnum,original?:{utc:string;input:string}):Result<string>
```

DATE文法は^([0-9]{4,})-([0-9]{2})-([0-9]{2})$、年>=1、安全整数、月1..12、日1..月末。閏年は年%400=0または年%4=0かつ年%100!=0。先頭0を含む年は数値化後4桁以上にゼロ埋めして再出力。暦日をnew Date('YYYY-MM-DD')へ渡さない。

local文法はDATE部分+T+[0-9]{2}:[0-9]{2}、任意の:[0-9]{2}と任意の.[0-9]{1,3}（小数は秒がある場合のみ）。時0..23、分秒0..59、小数は右0埋めでms、秒省略0。UTC文法は4桁年または符号付き6桁拡張年+同じ月日+T時分秒、任意1〜3桁ms、末尾Zのみ。UTCの各成分をsetUTCFullYear/setUTCHoursへ設定し全UTC成分の往復一致・有限epoch・toISOString成功を要求する。DateのTimeClip範囲外はoutOfRange。UTC→localが年<=0またはHTML inputへ設定後に読み戻せない場合もoutOfRangeとし、保存値は保持する。

fromInput日時はnew Date(0)にsetFullYear(y,m-1,d)→setHours(h,m,s,ms)。全local成分が一致しなければnonexistentLocalTime（DST欠落を含む）。有効ならtoISOString。original.inputとrawをparseした全成分が一致し、original.utcが有効ならoriginal.utcをそのまま返す（文字列の省略秒差で未編集情報を失わない）。P-03案は新規の重複時刻をJS Dateと同じ早い側UTCへ解決する。遅い側の外部UTCは未編集往復で維持する。失敗はthrowせずResult.error。未知のtype Enumだけ構成エラーBRUCE_DATE_TYPEとしてthrowする。

## UIIMPL-05 必要幅と無効化

計測型・手順の正本は05章。watchMeasure(host:HTMLElement,read:()=>number,service:LayoutMetricsService,destroyRef:DestroyRef):voidはafterNextRenderでregister、host/対象ResizeObserver、内容MutationObserver、document.fonts.ready/loadingdone、i18n/Input変更のinvalidateをrAF1件へ集約する。destroyで登録・全Observer/イベント・rAF解除。promise解決後はdestroyed確認。測定cloneを元DOMへ挿入しない。

Groupの子Layoutは登録済み必要幅を再帰的に参照する。登録の依存方向は親→子だけ。必要幅の算出では割当済み幅を読まず、自己要素再入をSetで検出しBRUCE_MEASURE_CYCLE。LayoutItemのmin-content必要幅は各子requiredの最大、ItemStackは各行requiredの最大。Groupはlegendと内容の最大+fieldset左右padding/border。Group内部が一行であるべきかを推測し、割当幅を再帰参照しない。
